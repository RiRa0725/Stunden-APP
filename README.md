# ZeitPol – iPhone/PWA-Grundlage

Diese Beispielversion bildet bewusst nur die **technische Grundlage für iPhone/PWA** ab.

Enthalten:
- Responsive Mobile-First-Oberfläche
- Safe-Area-Unterstützung für iPhone
- PWA-Manifest
- iOS-Home-Screen-Metadaten
- vorbereitete App-Icons
- Dark-Mode-Unterstützung
- Touch-freundliche Bedienelemente

Noch nicht enthalten:
- Service Worker
- Offline-Speicherung
- IndexedDB
- Cloud-Synchronisation

## Lokal testen

Die Dateien müssen über einen Webserver ausgeliefert werden. Für die echte iPhone-Installation wird HTTPS benötigt.

Danach Safari öffnen und über **Teilen → Zum Home-Bildschirm** hinzufügen.

## Nächster technischer Schritt

Service Worker + IndexedDB ergänzen und die vorhandenen ZeitPol-Daten damit offline speichern.
